# Customer Churn Analysis using Python & SQL

## Overview

This project analyzes customer churn behavior using Python, SQL, and data visualization techniques.

## Features

- Data Cleaning using Pandas
- SQL-based churn analysis
- Exploratory Data Analysis
- Churn Visualization using Matplotlib
- Business Recommendations

## Technologies Used

- Python
- Pandas
- SQL
- Matplotlib
- Jupyter Notebook

## Key Insights

- Month-to-month contracts had the highest churn rate.
- High monthly charges contributed significantly to churn.
- Long-term contracts improved customer retention.
